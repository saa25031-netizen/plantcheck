Firebase Console 設定手順

Firebase Firestoreで複数端末での共有保存を行うには以下のルール設定をFirebaseコンソールで行ってください。

1 Firestore データベースルールの開放

Firebase Console > Firestore Database > ルール タブを開き、以下に変更して「公開」をクリックします。 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
